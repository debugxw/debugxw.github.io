# 梦想的火焰熊熊燃烧 - 数据保存功能

## 功能说明

这个HTML应用现在支持数据自动保存功能，可以将表格数据保存到 `fire.json` 文件中，并在下次打开时自动加载上次保存的数据。

## 使用方法

### 1. 启动服务器

由于浏览器的安全限制，需要启动一个本地服务器来处理数据保存。提供两种服务器选择：

#### 选项A：Go服务器（推荐）
```bash
go run server.go
```

#### 选项B：Python服务器
```bash
python3 server.py
```

服务器将在 `http://localhost:8000` 启动。

### 2. 访问应用

在浏览器中打开 `http://localhost:8000/fire.html`

### 3. 数据保存机制

- **自动保存**：当用户输入数据并失去焦点时，系统会自动保存数据
- **计算后保存**：当表格数据更新计算后，也会自动保存
- **双重保障**：如果服务器保存失败，会自动保存到浏览器的localStorage作为备选方案

### 4. 数据加载

- 页面加载时会自动尝试从 `fire.json` 文件加载数据
- 如果文件不存在或加载失败，会尝试从localStorage加载
- 如果都没有数据，则显示空白表格

## 注意事项

1. 确保在启动服务器后再访问HTML文件
2. 数据会自动保存，无需手动操作
3. 如果服务器未运行，数据会保存到浏览器的localStorage中
4. 关闭浏览器后，localStorage中的数据仍然保留
5. 服务器保存的数据会永久保存在 `fire.json` 文件中

## 故障排除

如果遇到数据保存问题：

1. 检查服务器是否正常运行
2. 查看浏览器控制台的错误信息
3. 检查 `fire.json` 文件的权限
4. 确保网络连接正常

## 技术实现

### Go版本特性
- 使用Go标准库net/http包
- 支持CORS跨域请求
- 高性能并发处理
- 完善的错误处理
- 自动超时控制

### Python版本特性
- 使用Python标准库http.server
- 支持CORS跨域请求
- 提供localStorage作为备选保存方案
- 自动保存和加载机制

## 编译Go服务器（可选）

如果需要部署到其他环境，可以编译Go服务器：

```bash
# 编译为可执行文件
go build -o fire-server server.go

# 运行编译后的文件
./fire-server
```
